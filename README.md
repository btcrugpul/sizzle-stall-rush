Sizzle Stall Rush is an original 2D canvas cooking game: run a street food stall against the clock. Customer orders land on the order board with countdown timers; you fire up the grill, fry pan, noodle pot and chop board, assemble each dish on the plate from eight counter ingredients, and serve it before the timer runs out. Combos build your score, orders grow faster and more complex as the day goes on, and three lost hearts end the day.

## Run it

```sh
node serve.mjs
```

Then open http://localhost:8080 in a desktop browser and play with mouse or keys 1-8.
